1. Introduction

By creating this tutorial, I intended to make some commands I use on Linux (Ubuntu) to install and configure Argo CD on a Kubernetes cluster managed by Kind visible.

For illustrative purposes only (not the main purpose of this tutorial), I’m using Argo CD to manage the continuous deployment of a Java 25 application whose repository is in GitLab.

In this tutorial, I don’t use pre-built Bash scripts to prepare the environment (as I like to do in my daily life). Therefore, the focus of this tutorial is more EDUCATIONAL (aimed at Windows users) than OPERATIONAL. In the future, I plan to create a version that follows this latter approach, using many more Bash functions and scripts.

2. Prerequisites

2.1. Ubuntu installation

  1. Please choose a method to install Ubuntu and proceed with it.

    1. I am assuming that you’ll be running in a fresh Ubuntu installation.

      1. In my case, I’ll be running a VM running through QEMU/KVM.

    2. If you’re using Windows, my recommendation is: install Ubuntu in a WSL environment.

  2. This is latest version of Ubuntu where the following commands were tested:

    $ lsb_release -a

2.1.1. Install some useful packages (used by next steps)

  1. Open a new Bash terminal and run these commands:

    $ sudo apt update && sudo apt install -y \
  tree \
  curl \
  vim \
  bat \
  git \
  xsel

2.1.2. Do some simple configurations

  1. Configure your prompt to the most simple format:

    $ export PS1='$ '
$ echo "!!" >> ~/.bashrc

  2. Configure sudo to not ask confirmations:

    $ echo "$(whoami) ALL=(ALL) NOPASSWD:ALL" | sudo tee /etc/sudoers.d/$(whoami) >/dev/null && sudo chmod 440 /etc/sudoers.d/$(whoami)

  3. Configure your default editor to vim:

    $ export EDITOR=vim
$ echo "!!" >> ~/.bashrc

  4. Add and load some useful aliases (and functions):

    $ cat >> ~/.bash_aliases<<EOF
alias cat=batcat
alias k=kubectl
pbcopy() { xsel --clipboard --input; }
pbpaste() { xsel --clipboard --output; }
EOF
$ source ~/.bash_aliases

  5. Configure Git:

    $ git config --global --edit
$ git config --global diff.tool vimdiff
$ git config --global --add difftool.prompt false
$ git config --global alias.alias "! git config --get-regexp ^alias\\. | sed -e s/^alias\\.// -e s/\\ /\\ =\\ /"
$ git config --global alias.log-adog "log --all --decorate --oneline --graph"

2.7. Argo CD installation

  1. Install the argocd Kubernetes namespace:

    $ k create namespace argocd
$ k apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

  2. Install the argocd CLI:

    $ curl -sSL -o argocd-linux-amd64 https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
$ sudo install -m 555 argocd-linux-amd64 /usr/local/bin/argocd
$ rm argocd-linux-amd64

  3. Run Argo CD and expose its port 8080:

    $ k patch svc argocd-server -n argocd -p '{"spec": {"type": "LoadBalancer"}}'
$ log=~/argocd.log; k port-forward svc/argocd-server -n argocd 8080:443 &> $log &
$ tail -f $log # and press Ctrl+C
$ sudo ss -tnlp | grep 8080

  4. Copy the admin password to your clipboard:

    $ argocd admin initial-password -n argocd | head -1 | pbcopy

    Alternative command:

    $ k -n argocd get secret argocd-initial-admin-secret -o jsonpath='{.data.password}' | base64 -d | pbcopy

  5. Test the login / logout using the CLI:

    $ argocd login --insecure localhost:8080
Username: admin
Password:
'admin:login' logged in successfully
Context 'localhost:8080' updated

$ argocd logout --insecure localhost:8080
Logged out from 'localhost:8080'

  6. At this point you may want to follow the lab Getting started with Argo CD.

5.2. Creating the EchoController class

  1. Create the EchoController class:

    $ d=src/main/java/com/example/echo/controller; \
  (cd $TUT_HOME/code; rsync -R $d/EchoController.java $OLDPWD)

  2. Here is the content of this class:

    package com.example.echo.controller;

import org.springframework.web.bind.annotation.*;
import java.net.InetAddress;
import java.time.ZonedDateTime;
import java.util.Map;

@RestController
@RequestMapping("/api")
public class EchoController {

    @GetMapping("/echo")
    public Map<String, Object> echo(@RequestParam String msg) throws Exception {
        var serverIp = InetAddress.getLocalHost().getHostAddress();
        var timestamp = ZonedDateTime.now().toString();

        return Map.of(
                "message", msg,
                "serverIp", serverIp,
                "timestamp", timestamp
        );
    }
}

  3. Run the application:

    $ log=$(basename $PWD).log
$ ./gradlew bootRun &> $log &
$ tail -f $log

  4. Press Ctrl-C to kill tail (this will not kill the Spring Boot application).

  5. Test the results producted by this API:

    $ curl -s 'localhost:8080/api/echo?msg=test' | jq .
{
  "timestamp": "2025-10-12T17:29:47.905602102+01:00[Europe/Lisbon]",
  "serverIp": "127.0.1.1",
  "message": "test"
}

  6. Stop the application:

    $ kill %1

  7. Make your second Git commit:

    $ rm HELP.md
$ cat > .gitignore <<EOF

EOF
$ git add .
$ git commit -m 'Added EchoController'
